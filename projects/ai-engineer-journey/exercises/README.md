# Exercises

Each week's folder holds a starter module (`weekNN.py`) and its tests (`test_weekNN.py`).

```bash
journey check week-02     # run the tests and record the score
```

## Rules

1. **The docstring is the specification, and the tests are the proof.** Read both before coding.
2. **Don't edit the tests.** If you think one is wrong, ask the tutor.
3. **Tests ending in `_edge_case` are the point.** Empty input, zero, negatives, boundaries,
   bad input. Before coding, write the edge cases you expect in a comment, then compare
   with the tests.
4. **STRETCH** exercises use material from the following week. Do them last.
5. **Stuck for 20 minutes?** Ask the tutor for a _hint_. It gives progressively stronger
   hints, never the solution.

Your solutions are committed like any other work: they're part of the public record of
your progress. CI doesn't grade them; `journey check` does, and the results go to
`progress/results.yaml` and the dashboard.
