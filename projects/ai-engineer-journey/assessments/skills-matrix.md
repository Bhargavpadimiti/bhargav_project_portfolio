# Skills matrix

Re-rate yourself at the start (December) and at each checkpoint. Be honest: the gap
between **Now** and **Target** decides what the tutor emphasises next.

**Scale:** 0 = never heard of it · 1 = know what it is · 2 = can do it with help or docs ·
3 = can do it alone and explain the trade-offs · 4 = have done it in production / could teach it

**Demand** comes from [job-market research](../research/job-market-2026.md): High = in roughly 25% or more of AI engineer postings.
